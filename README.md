# Pip's Nursery (haX.baby Track 1)
Static site: index.html + assets/. No build step.
Run locally: `python3 -m http.server` then open http://localhost:8000
Deploy: drag this folder into Vercel / Netlify, or push to GitHub and enable Pages.
Extras: tap the flashlight button, play the block toys.
Easter egg: type "zzz" or tap the footer moon 5 times.
